# Long-term roadmap

Objective: build a maintained, practical Codex / Claude Code skill library, published in this GitHub repository. Each skill must have a precise trigger, an executable or worked example, real validation and a changelog entry.

## Milestone 1 — initial five workflows

- [x] Materials intake: inventory, duplicate evidence and a usable folder index.
- [x] Desktop triage: classification plan, collision handling and scoped file operations.
- [x] Source-backed writing: claim-to-source evidence ledger and reviewable draft.
- [x] Repository handoff: actual commands/results, remaining issues and handoff note.
- [x] Skill research: dated GitHub/X source ledger, deduplication and implementable shortlist.
- [x] Shared installer, Codex/Claude discovery paths, release ZIP and multi-platform CI.

## Milestone 2 — professional workflows

- [ ] Experiment report from existing results, preserving metric/protocol definitions.
- [ ] Meeting notes into tasks with explicit owners and unresolved decisions.
- [ ] Project documentation synchronization from verified code changes.
- [ ] Small-package release preparation with version/artifact/CI consistency.
- [ ] Bilingual professional editing with a factual preservation map.

Next selected workflow: **meeting notes to actions**, based on the initial forward research evaluation. Experiment reporting follows; maintain separate claim/protocol definitions.

## Each iteration

1. Read issue feedback and current repository state.
2. Research official docs and adjacent GitHub projects; use X only as dated discovery evidence.
3. Select one concrete workflow; avoid overlapping triggers.
4. Test a realistic baseline request, then develop the skill and helper only where useful.
5. Run script tests, skill validation, a realistic forward evaluation and CI.
6. Publish the verified change/release; report what actually shipped and what remains.

A roadmap file does not schedule autonomous runs. The Codex goal tracks continuation in this chat; no periodic automation or posting to X is configured.
