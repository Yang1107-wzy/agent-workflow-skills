# Professional workflow expansion

Deliver five additional independent skills, bringing the library to ten. Keep the original five intact. Use standalone standard-library helpers where they make outputs reproducible; use agent judgment for extraction, editing and semantic interpretation. Existing installer/validator discovers all sibling skill directories. No agent API, automatic external writes or new server.

1. **Meeting actions:** extract commitments and concrete proposed tasks, preserve speaker/date uncertainty and source line evidence. Output actions.md, actions.json, review.md. Validator verifies schema, exact evidence and line bounds without asserting semantic truth. Unknown owners/deadlines remain null. Relative deadlines require meeting context and an explicit resolution basis.
2. **Experiment reports:** summarize existing JSONL numeric results with explicit expected cases, successful-result coverage, units and protocol. Return deterministic counts/means and a publishable draft with limitations. No simulated or fabricated experiments. Compare only compatible protocols/units; means are conditional on returned numeric rows.
3. **Documentation sync:** connect verified code changes to relevant user/developer documents. A repository helper extracts a scoped Git diff/change manifest between explicit commits; agent updates only affected docs and validates commands/examples. Rename/deletion and dirty state are visible. No automatic Git actions or unrelated docs rewrites.
4. **Release preparation:** check local versions, changelog, selected artifacts, hashes and source status. Prepare notes/checklist/assets for an authorized release; distinguish local readiness from actually published state. No built-in external publishing. Support Python pyproject/Node package JSON and generic explicit version projects, without imposing a package manager.
5. **Bilingual editing:** refine or translate professional English/Chinese prose while preserving user facts, numbers, named entities, dates, scope and evidence status. Produce edited prose plus a preservation map; helper checks literal anchors/counts/context as evidence, not translation quality. Do not add unsupported achievements or stronger claims.

All skills: narrow name/description frontmatter, <=500-word focused body, discoverable local references, optional Codex UI metadata; exact skill folder/name match. Python >=3.10, zero runtime third-party dependencies, UTF-8 I/O, documented exit codes; public examples synthetic. Scripts never mutate input files or overwrite output files. No sending messages/calendar tickets or external writes except separate user authorization. Each skill must have unit/subprocess failure regressions and an isolated forward user-task evaluation. Publish verified sources + release ZIP + checksums, validate extraction/installation, verify Linux/Windows/macOS CI. Declare Claude runtime execution limits accurately.
