# Intake deliverables

Produce `inventory.json` (machine-readable helper output), `inventory.md` (readable file list), and `material-index.md` containing:

| Material or group | Purpose/topic | Selected version | Evidence/status | Next action |
| --- | --- | --- | --- | --- |

Use paths relative to the selected root. Separate observed file properties (hash, bytes, suffix) from content-based classifications and user-confirmed facts. Label a preferred copy without approval evidence as **preferred, approval unverified**. Do not fill missing dates or infer submission from a PDF's presence.

Include byte-identical duplicate groups and a short review list for ambiguous versions, unreadable files or skipped entries. Preserve existing filenames in the inventory. If the user supplied a required naming convention, use it for newly created outputs only within the authorized scope.

Example: `proposal-final.md` says “working draft,” and the user calls it “probably approved.” Keep it as a candidate; quote the observed status in the index and leave approval unverified. Do not invent an approval date.
