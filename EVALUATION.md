All scenario files are synthetic. Helpers were tested independently from agent behavior. Evaluation agents had the skill and minimum task artifacts; they wrote results only in isolated evaluation folders. No real user desktop files were changed.

The initial no-skill baseline handled the first three scenarios competently. These evaluations establish useful artifacts and helper behavior; they do not claim a measured improvement in model performance or a randomized A/B comparison. The value here is reusable output contracts and deterministic helpers.

Script regression coverage includes file hashes, duplicate groups, non-overwriting destinations, nested copy paths, source containment in installation, UTF-8 output under legacy consoles, actual Git state, evidence structure, explicit source-ranking metadata and self-contained release packaging.

The bundle metadata, local resources and scripts are checked. Evaluations ran through available Codex agents; Claude Code folder layout follows fetched official docs, but an actual Claude Code client session was not run. No guarantee of identical behavior across models is claimed.

Raw evaluation logs are excluded from Git and the release archive because they contain machine-specific paths. This summary records the inspected outcomes without publishing local environment details.
